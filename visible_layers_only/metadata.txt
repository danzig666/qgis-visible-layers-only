description=Adds a toggle button to the Layers panel toolbar that lists only the currently visible layers.
about=Adds a checkable button to the native Layers panel toolbar. When enabled, the Layers panel hides every layer (and every group without visible content) that is not currently shown on the map canvas. It only changes what the panel displays: layer visibility, order and project contents are never modified. Works on QGIS 3.x (Qt5) and QGIS 4.x (Qt6).
